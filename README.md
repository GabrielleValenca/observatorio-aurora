# Observatório Aurora

## Tema

O Observatório Aurora é um site desenvolvido com o tema Astronomia, apresentando informações sobre o universo, corpos celestes, descobertas espaciais e curiosidades astronômicas.

## Integrantes

* Giovanna Carolina Moreira – RA 250859
* Gabrielle Conceição Valença – RA 250797

# Páginas do Projeto

### Home

Página inicial contendo apresentação do projeto, carrossel de imagens e destaques sobre astronomia.

### Galeria

Página com imagens, novidades e lançamentos relacionados ao universo e à exploração espacial.

### Contato

Página com formulário de contato, informações institucionais e mapa incorporado.
